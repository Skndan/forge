# Forge v0.2 — Data Layer ✅

**Released:** 2026-06-05

## Summary

This release builds Forge's core data services for realtime subscriptions, file storage, and background workers. All services are built in TypeScript on Bun, fully unit-tested, and integrated into the existing Docker Compose stack.

## What Was Built

### Group 1 — Realtime Service (`packages/realtime/`)

| Code | Feature | Details |
|------|---------|---------|
| R-001 | WebSocket server | Bun WebSocket on port 3001 with JWT auth |
| R-002 | Postgres LISTEN | pg_notify on `forge:storage`, `forge:functions`, `forge:webhooks` |
| R-003 | Valkey pub/sub | Multi-instance fan-out via ioredis pub/sub |
| R-004 | Subscription management | Per-connection subscriptions by table, filter, row_id |
| R-005 | Reconnection handling | Connection state lifecycle with cleanup |
| R-006 | Channel filtering | Match events by table, op filter, row_id |
| R-007 | Unit tests | 24 passing (auth, subscriptions, channel filtering) |

### Group 2 — Storage Service (`packages/storage/`)

| Code | Feature | Details |
|------|---------|---------|
| S-001 | S3-compatible client | @aws-sdk/client-s3 configured for RustFS |
| S-002 | Presigned upload URLs | 15-min expiry, optional metadata |
| S-003 | Presigned download URLs | 1-hour expiry |
| S-004 | Metadata CRUD | Postgres storage_metadata: create, upsert, read, list, update, delete |
| S-005 | Bucket management | storage_buckets table + CRUD (migration 006) |
| S-006 | CORS configuration | Default permissive, restricted, and custom CORS rules |
| S-007 | Unit tests | 27 passing (S3 client, buckets, CORS, errors) |

### Group 3 — Workers

**Webhook Worker** (`packages/worker-webhook/`)

| Code | Feature | Details |
|------|---------|---------|
| W-001 | pgmq delivery loop | SELECT FOR UPDATE SKIP LOCKED via pgmq.read() |
| W-002 | Exponential backoff | 10s → 30s → 2min → 4min... (capped at 1hr) |
| W-003 | HMAC-SHA256 signing | X-Forge-Signature-256 header |
| W-004 | Healthcheck | HTTP health endpoint on port 9100 |
| W-005 | Unit tests | 12 passing |

**Scheduler Worker** (`packages/worker-scheduler/`)

| Code | Feature | Details |
|------|---------|---------|
| W-006 | Cron-based triggers | Full 5-field cron parser (wildcards, steps, ranges, CSVs) |
| W-007 | Healthcheck | HTTP health endpoint on port 9101 |
| W-008 | Unit tests | 15 passing |

**Audit Worker** (`packages/worker-audit/`)

| Code | Feature | Details |
|------|---------|---------|
| W-009 | Audit event consumer | pgmq → forge.audit_logs, field validation, batched |
| W-010 | Healthcheck | HTTP health endpoint on port 9102 |
| W-011 | Unit tests | 7 passing |
