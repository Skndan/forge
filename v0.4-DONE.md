## Key Design Decisions

- **File-based sandbox fallback** (`FORGE_SANDBOX_MODE=file-based`) for development without Docker
- **Buffered log collection** with configurable flush interval (1s default) and max buffer size (100 entries)
- **Warm pool rebalancing** every 30s with idle eviction after 5 min
- **Scoped JWT** uses HS256 with 60s default TTL, supports table/bucket allow-lists
- **Deployment API** protected by admin service token (Bearer auth)
