# Forge v0.1 — Foundation ✅

**Date:** 2026-06-05
**Status:** Complete

## What was built

### 🏗️ Project Structure
- Turborepo monorepo with 11 package directories
- Root configs: tsconfig, tsconfig.base, prettier, eslint, turbo.json, .gitignore, .dockerignore
- .env.example with all configuration variables

### 🐳 Docker Compose
- 9 services: Gateway, Keycloak, Postgres 16, Realtime, Function Runner, Webhook Worker, RustFS, Valkey, Dashboard
- Healthchecks on all services
- Named volumes for Postgres and RustFS
- Dockerfiles for all buildable services

### 📦 Shared Types (`@forge/types`)
- Full TypeScript type definitions: Tenant, User, StorageMetadata, FunctionDefinition, WebhookSubscription, WebhookDelivery, AuditLog
- API request/response types, error codes

### 🗄️ Database (`packages/database`)
- 5 SQL migration files (001-005)
- Tables: tenants, users, storage_metadata, function_definitions, webhook_subscriptions, webhook_deliveries, audit_logs
- RLS policies with app.current_user_id/current_roles/current_tenant_id session variables
- pg_notify triggers on INSERT/UPDATE/DELETE (channels: forge:storage, forge:functions, forge:webhooks)
- pgmq extension for webhook delivery queue
- Migration runner (TypeScript)

### 🔐 Auth (Keycloak)
- Full realm.json with 3 OIDC clients:
  - forge-api (confidential, direct grant + service accounts)
  - forge-dashboard (public SPA)
  - forge-flutter (public mobile)
- Custom JWT mappers: tenant_id, plan, roles, client_roles
- Init script for realm import

### 🚪 Gateway (`packages/gateway`)
- Bun + Fastify server
- JWKS fetch with 15-minute in-memory cache (jose)
- JWT verification middleware
- Postgres session variable middleware
- Admin token middleware (X-Admin-Token header)
- Routes:
  - `GET /v1/health` — health check
  - `POST /v1/db/query` — SELECT-only DB queries
  - `POST /v1/storage/upload-url` — presigned upload URL
  - `GET /v1/storage/download-url` — presigned download URL
  - `POST /v1/functions/invoke` — invoke functions
  - `POST /v1/webhooks` — manage webhook subscriptions
  - `GET /v1/webhooks` — list webhooks
  - `GET /v1/auth/me` — current user info
  - Admin routes: GET /v1/admin/tenants, GET /v1/admin/users, GET /v1/admin/health
- CORS support
- In-memory rate limiting (per-IP)
- Error handler with ForgeError hierarchy
- **38 unit tests (all passing)**

### 🧪 Testing
- E2E Docker Compose smoke test script
- Auth unit tests (extractToken, verifyToken)
- Error class tests
- Route logic tests for all endpoints

### 🛠️ Scripts
- `scripts/init.sh` — development bootstrap
- `scripts/wait-for-health.sh` — healthcheck waiter
- `scripts/e2e-test.sh` — E2E smoke test
- `packages/auth/keycloak/init.sh` — Keycloak realm import
