# Forge v0.3 — Frontend + SDK ✅

**Released:** 2026-06-05

## Summary

This release adds the Admin Dashboard (Next.js) and Flutter SDK (Dart) to the Forge platform. The dashboard provides a full admin UI for managing all Forge resources, and the Flutter SDK offers a comprehensive client library for mobile app development.

### API Client

The dashboard includes a complete typed API client (`src/lib/api.ts`) with functions for:
- Tenants: `listTenants()`
- Users: `listUsers()`, `getUser()`, `updateUser()`
- Tables: `listTables()`, `getTableInfo()`, `queryTable()`, CRUD rows, RLS policies
- Storage: `listBuckets()`, `createBucket()`, `listFiles()`, `uploadFile()`
- Webhooks: CRUD + delivery logs
- Functions: CRUD + test invoke
- RBAC: roles, permissions, user-role assignment
- Health: `getHealth()`

### SDK Architecture

```
ForgeClient (singleton)
├── AuthService          → PKCE login, token management, session restore
├── DatabaseService      → SQL queries via /v1/db/query
├── StorageService       → Presigned upload/download, file bytes/path
├── FunctionsService     → Sync/async function invocation
└── RealtimeService      → WebSocket subscription with Dart Stream

ApiClient (Dio)
└── AuthInterceptor      → Bearer token, auto-refresh on 401

ErrorHandler
└── withRetry()          → Exponential backoff, jitter, configurable max

AuthState
├── ChangeNotifier       → BuildContext-safe access
├── StreamController     → Reactive stream for state changes
└── FlutterSecureStorage → Token persistence
```

### Usage Example

```dart
import 'package:forge_flutter_sdk/forge_flutter_sdk.dart';

void main() async {
  final forge = ForgeClient.instance;
  await forge.initialize(
    gatewayUrl: 'http://localhost:3000',
    keycloakUrl: 'http://localhost:8080',
    realm: 'forge',
    clientId: 'forge-app',
  );

  // Auth
  final user = await forge.auth.login();

  // Database
  final result = await forge.database.query(
    query: 'SELECT * FROM items WHERE tenant_id = \$1',
    params: [user!.tenantId],
  );

  // Storage
  await forge.storage.uploadFile(
    bucket: 'uploads',
    path: 'avatar.jpg',
    fileBytes: imageBytes,
    contentType: 'image/jpeg',
  );

  // Functions
  final output = await forge.functions.invoke(
    functionId: 'func-123',
    payload: {'action': 'process'},
  );

  // Realtime
  forge.realtime.connect();
  forge.realtime.subscribe(table: 'items');
  forge.realtime.events.listen((event) {
    if (event.type == RealtimeEventType.message) {
      print('Change: ${event.data}');
    }
  });
}
```
